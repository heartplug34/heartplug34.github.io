容声冰箱国补计算器 — 使用说明
================================================================
  v3.3  ·  由 heartplug34 制作


【适用范围】重要
  本工具以【容声冰箱】的国补政策为基准计算。

  默认已内置 2026 年 15% 的国补比例；如当地或品牌政策不同，
  可在「设置 → 外观」里自行调整国补比例。


【怎么发给别人】
  只发这一个文件：价保计算器.exe
  微信 / QQ / 邮件 / U 盘 都行，不需要打 zip。


【对方怎么装】
  第一步：双击「价保计算器.exe」

  第二步：程序会弹出一个框问你要不要信任它的内部证书，
          并且会显示证书指纹让你核对：

              384E CB3B CB41 0C1B D66E F31E 06A7 DDD3 06C9 EEB6

          核对无误点「是」
          接着系统会弹出「安全警告」问：您要安装此证书吗？
          再点一次「是」

          不想信任也可以点「否」，程序照常能用，
          只是每次启动会提示「未知发布者」。

  第三步：证书装好后，程序直接打开就能用。
          以后不会再有任何提示。

  · 证书只装到「当前用户」，不需要管理员权限
  · 将来想撤销：控制面板 → 证书 → 用户证书 → 删掉该证书


【单开限制】
  程序同时只能开一个。重复双击会弹窗提醒，
  并把已经开着的窗口切到前台，不会开出第二个窗口。


【窗口自适应】
  窗口拉宽 → 三栏（输入 / 参考 / 结果）
  窗口缩窄 → 两栏：左侧「时效 + 差价核算 + 价保速查 + 填写指引」，右侧「核算结果」
  再缩窄     → 单栏，核算结果直接放最上面
  也可以在「设置 → 布局」里手动锁定单栏专注模式。


【如果还弹出"Windows 已保护你的电脑"】
  这是 SmartScreen 对"从网络下载的文件"的通用拦截，与证书无关，
  自签名证书无法消除它。两种办法：
    · 点「更多信息」→「仍要运行」
    · 让 IT 用组策略统一放行该路径


【系统要求】
  Windows 10 1607 LTSC / 1809 / 21H2 及以上（x64）
  Windows 11 任意版本
  · Windows 10 家用版已停止官方支持，程序仍能运行但不在测试范围内
  · Windows 7 / 8.1 不支持
  · 自包含单文件，无需安装 .NET 运行时

  界面底色会自动匹配系统（半透明，能透出桌面背景）：
    Windows 11        → Mica（云母材质）
    Windows 10 1809+  → Acrylic（亚克力）
    Windows 10 1607   → 不透明纯色

  透明效果取决于系统与「设置 → 个性化 → 颜色」里的透明设置；
  若看不到透明，属于系统未开启或显卡驱动不支持，不影响功能。
